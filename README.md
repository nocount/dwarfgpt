# dwarfgpt

Attempt at a bilingual GPT-2-scale model that speaks English and Neo-Khuzdul, by
mixing a synthetic Neo-Khuzdul corpus into a [nanochat](https://github.com/karpathy/nanochat)
pretraining run. Full plan in [`khuzdul_nanochat_plan.md`](khuzdul_nanochat_plan.md).

## Quickstart

If you have `make`:

```
make install                # uv sync, installs deps into .venv
make test                   # run the Python module tests
make extract                # regenerate data/*.json from the .xlsm (slow, ~3 min)
```

Or directly via `uv` (works on plain Windows without GNU make):

```
uv sync
uv run pytest khuzdul_translator/tests/ -v
uv run python scripts/extract_tables.py
uv run python -m khuzdul_translator --phrase "dwarves"
```

How to read it

Klazan share
Fraction of pretraining tokens that are Klazan documents. They replace English, so every run sees the same total. In the "pairs" runs a tenth of that share is English/Klazan text alternating paragraph by paragraph.
English val bpb
Bits per byte on ClimbMix validation, computed as nanochat's training loop does. The English cost is its rise over the control.
CORE
nanochat's in-context benchmark suite. At this model size it moves by about a point between checkpoints of one run, so it can't resolve these differences.
EN→KZ exact
The model's Klazan matches the deterministic translator's output character for character.
KZ→EN round trip
Klazan has one pronoun for he, she and it, so exact English undercounts. This asks whether the model's English translates back to the source Klazan. The ceiling is the reference English's own round-trip rate.
Valid Klazan words
Share of words in sampled story continuations that the Klazan validator accepts as lexicon words.
